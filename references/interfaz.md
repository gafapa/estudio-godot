# Interface design

Use established gameplay loops and character readability requirements. Research navigation, HUD, controls, feedback, onboarding and accessibility in reference games and on the target platform. Cite sources in `docs/referencias/interfaz.md`.

Write `docs/design/ux/pantallas.md` with screen purpose, entry/exit paths, navigation diagram, persistent/contextual HUD, controls by platform, remapping where relevant, feedback timing, onboarding and key-screen wireframes. Distinguish base viewport from physical pixels and device density.

Use containers, anchors, safe areas, readable text, keyboard/controller focus when supported, and redundant cues instead of color alone. Define logical touch target sizes and verify them on the real device. Capture multiple aspect ratios and inspect images. Record unavailable hardware checks as pending.
