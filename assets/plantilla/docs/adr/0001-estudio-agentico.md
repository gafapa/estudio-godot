# ADR 0001 - Local Godot studio

- Status: accepted for installation, {{DATE}}.

## Context
Parallel delivery needs ownership, reproducible validation and persisted decisions.

## Decision
Scoped roles, disjoint tickets, contracts written by the Architect, independent reviews where available and gates against immutable commits. Godot {{GODOT_VERSION}}, {{MODE}} mode. Documentation and code identifiers/comments are English.

## Alternatives
Sequential work is supported without delegation; disclose the review limitation. Add roles only to remove actual bottlenecks.

## Consequences
Review consumes tokens and time. Concurrency must fit capacity. Metrics and screenshots complement human feedback; they do not establish enjoyment.
